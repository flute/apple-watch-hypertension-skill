# 新手教程：开通因地区限制不可用的高血压通知

适合尚未开放高血压通知的地区。准备好 **Mac、支持该功能的 Apple Watch、配对的 iPhone 和 USB 数据线**。不需要会编程，也不需要提前安装 Python、Git 或 Homebrew。

选你已经在用的 AI：**[Claude Code](#claude-code)、[Codex](#codex)、[WorkBuddy](#workbuddy)**。这里安装的是 Skill；AI 软件本身需要先安装、登录，并能在这台 Mac 执行操作。

## Claude Code

### 下载

1. 打开[最新下载页](https://github.com/flute/apple-watch-hypertension-skill/releases/latest)，在 **Assets** 下载 **apple-watch-hypertension.zip**。
2. 打开“访达”（Dock 上的蓝白笑脸图标），左边点“下载”。
3. 双击 ZIP 解压。若浏览器已经解压，直接打开文件夹。
4. 文件夹内应有 **SKILL.md、install.command、scripts**。下载页的 **Source code** 是给开发者的，不选它。

### 打开终端，运行安装

1. 按 **⌘ Command + 空格**，输入“终端”或“Terminal”，按回车。
2. 在出现的窗口输入 `bash `，**末尾有一个空格，先不要回车**。
3. 切回访达，把 **install.command** 拖进终端，文件路径会自动填入。
4. 点回终端，按回车。出现菜单后，输入 **2** 并回车。
5. 等末尾显示 **“安装完成 / Setup complete”**。下载速度因网络而异；明确报错时先看后面的排错说明。
6. 回到 Claude Code，新开对话，发送下面的指令。若找不到技能，重启 Claude Code；仍找不到就将安装末尾显示的完整路径给它。

安装程序自动准备独立的 Python 3.11 和依赖，不修改系统 Python，不需要管理员密码、sudo 或 Xcode。若系统要求安装开发者工具，取消后按上面的步骤重试。

其他菜单选项：**1** 为 Codex，**3** 只准备当前文件夹，**4** 为自定义技能目录，**q** 退出。

## WorkBuddy

1. 在 Mac 浏览器打开[最新下载页](https://github.com/flute/apple-watch-hypertension-skill/releases/latest)。
2. 找到 **Assets**，下载 **apple-watch-hypertension-workbuddy.zip**。保留 ZIP，不用解压。
3. 打开 WorkBuddy，进入技能管理，选择**添加技能 / 导入 ZIP**，选中下载的文件。按钮名称可能随版本变化。
4. 等技能出现在列表中，新开一个对话，发送下面“开始开通”中的指令。
5. 让 AI 自动准备环境，再检查手机。安装成功不等于功能已开通。

**提示无法访问技能文件或准备环境？**

先让 WorkBuddy 检查能否在这台 Mac 执行命令。若只是找不到导入目录，可另下载普通的 **apple-watch-hypertension.zip** 并解压，按上面 Codex 的终端步骤运行安装文件，但菜单选择 **3**。然后把保留的文件夹完整路径告诉 WorkBuddy，让它读取这里的 SKILL.md、使用这里的脚本。

如果只能在云端运行命令，就不能直接控制这台 Mac 的 USB；换用能在本机执行的模式或 Agent。WorkBuddy 的导入格式已适配，尚未完成实机验证。

## 开始开通

把这段话发给 AI：

> 使用 apple-watch-hypertension，帮我开通因地区限制不可用的 Apple Watch 高血压通知。先检查设备并准备本地运行环境。我同意通过 USB 临时使用香港定位；需要我操作时请提示并等待。结束后停止发送，确认真实定位恢复，再确认高血压通知仍开启。

如果功能本来就可用，按健康 App 的正常流程开启即可。这个工具帮助处理地区不可用的情况，不能让不支持的硬件或不符合资格的用户通过设置。

## 使用时需要你做什么

Agent 会在需要时提出具体操作。不要提前随意修改健康资料或定位设置。

1. **连接手机**：把与手表配对的 iPhone 用数据线接到 Mac。解锁 iPhone；若手机提示“信任此电脑”，自己点信任并输入手机密码。充电线不一定支持数据；连接失败时换数据线/接口。
2. **操作手机界面**：Mac 能用“iPhone 镜像”时由 Agent 检查可用工具；密码由你自己输入。如果没有镜像或控制工具，你直接在手机操作，告诉 Agent 实际结果。无需为了流程向聊天发送密码。
3. **记录真实位置**：临时定位之前，在“地图”点当前定位，查看新的当前位置地址。自己或 Agent 私下记下用于恢复比较；无需公开住宅地址、截图、设备序列号。
4. **身份来源**：Agent 会检查本地身份；缺少时说明自有身份或指定 DiPlay 实验身份的选择。证书和私钥不在发布包里。实验身份可能失效，不能反复重试承诺必成。
5. **验证香港定位**：临时发送开始后打开地图，点当前定位。必要时按 Agent 指示进入“设置 → 隐私与安全性 → 定位服务”，关闭，确认关闭后等至少 10 秒，再打开，返回地图刷新当前位置。菜单以你的 iOS 实际界面为准。只有新当前位置确实在香港才算成功，发送日志的 ACK 不算。
6. **回答健康问题**：到“健康 → 头像 → 健康检查清单 → 高血压通知”，按当前界面继续。年龄、是否曾被确诊等必须按事实填写。“血压偏高/临界”不能让 Agent 自行推断曾否确诊；不确定时先问清楚，不要为开通改生日或病史。
7. **结束和恢复**：Agent 停止发送后，你按提示拔掉 USB。刷新地图当前定位，必要时恢复定位服务原始状态；等新地址回到实际位置。然后再次打开健康，确认高血压通知仍显示开启。

发送单次最多十分钟。等你回答时计时不会暂停；时间不够就先停下并恢复，再说明下一步，不应偷偷续时。发送前让 Agent 把本地工具的完整路径和停止方法写给你，特别是 WorkBuddy 的本地目录。你可以随时说“停止并恢复真实位置”。

## 怎样才算完成

请让 Agent 明确给出这五项结果，并说明是它看到的还是你确认的：

- 香港当前位置确实生效（若走了临时定位路径）。
- 健康中高血压通知已开启。
- 发送进程已经停止。
- 拔线后，新地图定位回到真实位置。
- 恢复后重新打开健康，通知仍开启。

安装完成、协议认证成功、地图旧卡片、天气变化都不能替代这些检查。没有出现通知也不能凭开关判断疾病情况；本流程没有验证未来永久保留或实际告警送达。

## 常见问题

| 看到的情况 | 怎么做 |
| --- | --- |
| 安装时提示 `command not found: python3` | 你用了旧教程的 Python 命令。用上面的 Codex 安装步骤的 `bash` 和拖文件方式。 |
| 系统提示安装开发者工具 | 取消后按上面的 Codex 安装步骤重试；本安装入口不需要 Xcode。 |
| 下载超时、连接失败、校验失败 | 停止，不继续执行未知文件。保留最后几行错误让 Agent 分析；不要关闭证书验证或换不明镜像。 |
| 提示已有安装 | 安装程序不会覆盖旧版。按“更新和卸载”一节更新；不要反复重试。 |
| 下载完成但依赖安装失败 | Skill 可能已复制但环境未就绪。终端会先打印“环境准备目录”。在访达按 ⌘ + Shift + G，粘贴该路径回车，找到 install.command，按上面的 Codex 安装步骤运行并选 **3**。若终端已关闭，Codex 打开 `~/.agents/skills/apple-watch-hypertension`，Claude Code 打开 `~/.claude/skills/apple-watch-hypertension`；WorkBuddy/选 3 模式打开你保留的工具文件夹。若目录不存在，重新运行原始安装即可。 |
| Agent 说找不到技能 | 新开对话/重启宿主；把完整安装路径给它，让它读取 SKILL.md。 |
| 没有控制手机的工具 | 由你在 iPhone 上操作并反馈。无需替 Agent 安装未知远程控制软件。 |
| 无法检测到 USB iPhone | 检查解锁、信任、线缆和接口；尽量只连接一部 iPhone，再让 Agent 检查。 |
| 功能仍然显示不可用 | 记录当前页面和错误，停止发送、恢复真实位置。不能据此伪造健康信息或无限重试。 |
| `uv version mismatch` | 先停止发送并完成恢复。访达按 ⌘ + Shift + G，打开 `~/Library/Application Support/apple-watch-hypertension/tools`，仅将里面的 `uv` 文件移到废纸篓，再运行安装入口（已有技能选 3）。不要删除身份或会话目录。 |
| 想中途退出 | 对 Agent 说“停止发送并恢复真实位置”；关闭聊天或终端窗口不等于停止后台发送。 |

**Agent 没反应时的停止办法：**

先在访达按 **⌘ + Shift + G**，Codex 输入 `~/.agents/skills/apple-watch-hypertension`，Claude Code 输入 `~/.claude/skills/apple-watch-hypertension`，回车打开；WorkBuddy/人工协作打开你保留的本地工具目录。进入 scripts 文件夹。

打开终端，输入 `bash `，把安装目录中的 `scripts/run.command` 拖进去，接着输入空格和 `sessions`，回车。它只列出本地会话，不连接手机。在 JSON 输出中找 **`"process_alive": true`** 的那一项，复制同一项的 **`"session"`** 后面引号中的实际值，不包含引号。例如 `"session": "abc123…", "process_alive": true`（示意，不能照抄）。probe 与正式发送是不同 ID，不能随便选最后一条。若所有项都是 false，当前列出的进程均已停止。

再用同样方式拖入 `run.command`，在后面输入 ` stop --session `，粘贴刚才的实际 ID，回车。随后用 ` status --session ` 和同一 ID 检查，看到 `process_alive: false` 才是进程已停。不要照抄“SESSION”占位符。实在不理解，先拔 USB、确认手机定位服务恢复原状，并找 Agent 协助检查；后台还有独立的十分钟上限。

终端中 **Control + C** 可以中断正在前台运行的下载/命令，但不会保证已独立启动的发送进程停止。不要把 Command + C（复制）当作中断。

## 更新和卸载

**更新：**先停止所有发送，完成真实定位恢复，退出 Agent。找到旧技能目录，将整个 `apple-watch-hypertension` 文件夹移到技能父目录以外作为备份（仅改名留在技能目录下可能重复加载）。然后下载新发布包，重新安装。新版本成功检查后再删除备份。不要覆盖正在运行的目录。

Codex 默认技能目录为 `~/.agents/skills`，Claude Code 为 `~/.claude/skills`。`~` 表示你的个人文件夹。在访达按 **⌘ Command + Shift + G**，粘贴路径并回车即可打开隐藏目录。WorkBuddy 用其技能管理界面更新/移除；同时处理你保留的本地工具文件夹。

**卸载：**先停止发送并恢复手机，再从宿主移除技能或将对应技能文件夹移到废纸篓，重新打开宿主。卸载技能不会自动关闭健康中的通知。

本地凭据、会话和工具独立存放于：

`~/Library/Application Support/apple-watch-hypertension/`

这包含私密数据，不要上传到 GitHub。确认不再需要后，可用上述访达“前往文件夹”方式打开并移到废纸篓。不要在发送中删除它。如果删除了共享工具目录，其他安装副本需要重新准备环境。
