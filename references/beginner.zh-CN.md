# 第一次使用：从下载到完成核验

这份教程按“从没用过终端”写。你不需要会编程，也不需要预装 Python、Git、Homebrew 或 Xcode。**需要一台 Mac**；Windows、手机聊天窗口或云端电脑不能直接替代这台连接 iPhone 的 Mac。

本项目帮助设置的是 Apple Watch **高血压通知**，不会让手表显示收缩压、舒张压。设备和使用资格以 Apple 当前要求为准。一次成功案例不代表每个地区、系统、型号都可用。

## 1. 先选你要用的 AI

- 已有 **Codex 或 Claude Code，并且它可以在这台 Mac 执行命令**：按下面安装。
- 用 **WorkBuddy**：先看第 5 节，再准备本地运行环境。
- 只有 **豆包或 DeepSeek 网页/手机聊天**：先看[适配说明](agents.md)。它可以解释步骤，但不能因为你上传了 Skill 就自动获得 USB 权限。小白优先使用具备本地执行能力的 Agent。
- “DeepSeek 模型 + Claude Code”等组合，按 Claude Code 安装。模型品牌和运行程序是两回事。

本教程安装的是技能和本地工具，不会替你安装、注册或购买 AI 产品。Agent 自身的安装、登录、服务费用按其官方说明办理。USB 工具本身不需要 AI API Key；不要把密码、API Key 发到聊天里。

## 2. 下载并解压

1. 在 Mac 的浏览器打开[最新发布页](https://github.com/flute/apple-watch-hypertension-skill/releases/latest)。
2. 展开页面底部 **Assets**（文件列表）。
3. 点击 **apple-watch-hypertension.zip**。不要选 Source code；它们面向开发者。
4. 打开“访达”（Dock 上蓝白笑脸图标），左边点“下载”。
5. 找到下载的 ZIP，双击解压。如果浏览器已经自动解压，会直接出现文件夹。
6. 打开解压后的文件夹，应看到 **SKILL.md、install.command、scripts**。如果没看到，再进入里面一层。
7. 暂时不要删除这个文件夹。WorkBuddy/人工协作模式还会用它。

无法访问 GitHub 或下载中断时，先解决网络访问，或让可信的人转交原始发布 ZIP。不要随便替换下载地址、运行陌生人的“加速脚本”。完整性校验文件在同一发布页；需要时可请 Agent 对照 SHA256SUMS 检查。

## 3. 打开“终端”并运行安装文件

“终端”是 macOS 自带的应用，不需要另外下载。

1. 同时按 **⌘ Command + 空格**，出现系统搜索框。
2. 输入 **终端**（也可以输入 **Terminal**），按回车。
3. 会出现一个能输入文字的窗口。若搜索打不开，在访达 → 应用程序 → 实用工具 → 终端中打开。
4. 在终端输入以下内容，注意 **bash 后面有一个空格**，先不要按回车：

   `bash `

5. 切回访达，把文件夹里的 **install.command** 拖进终端窗口。终端会自动填写文件路径。
6. 点回终端，按回车。一次只运行一份，不要连续重复按回车。

你会看到菜单：

```text
1) Codex
2) Claude Code
3) 仅准备当前目录 / Prepare this folder (WorkBuddy/manual)
4) 其他 Agent 的技能目录 / Custom skills parent
q) 退出 / Quit
```

输入数字再按回车：

- **1**：安装到 Codex 用户技能目录。
- **2**：安装到 Claude Code 用户技能目录。
- **3**：在下载的文件夹里准备运行环境。供 WorkBuddy、其他 Agent 或人工协作使用，不会自动注册到 Agent。
- **4**：只适合已知道宿主技能目录的人。随后输入以 `/` 开头的完整“技能父目录”，安装程序会在其下创建 `apple-watch-hypertension` 文件夹。不要照抄示例中的占位文字。
- **q**：退出，不下载、不安装。

首次安装会下载固定版本的 uv、由 uv 管理的 Python 3.11，以及锁定的 Python 依赖。**Python 不应假设已经有**：即使电脑有 `python3`，也未必符合本项目版本要求。这里自动准备独立环境，不修改系统 Python，不编辑你的终端启动配置。

下载速度因网络不同而变化。看到进度继续变化就等待；若明确报错，不要当作成功。末尾应显示 **“安装完成 / Setup complete”** 和安装路径。它没有连接手机，也没有开始发送定位；同样不代表健康功能已经开通。

安装不需要管理员密码或 `sudo`。使用上面的“bash + 拖入文件”方式即可，不需要双击运行文件、关闭 Gatekeeper 或安装 Xcode。若其他软件提出这些要求，先把提示文字交给 Agent 判断。

## 4. 在 Codex / Claude Code 中使用

1. 回到 AI 程序，重新加载技能，或新开一个对话。若仍找不到，退出后重新打开程序。
2. 粘贴下面整段：

> 使用 apple-watch-hypertension，帮我检查并开通 Apple Watch 高血压通知。先确认你能在这台 Mac 执行本地命令。若需要，我同意用本地 USB CarKit 临时提供香港定位。需要我操作时请一次说清一件事并等待；结束后确认发送已停止、真实位置恢复，而且通知仍开启。先做环境检查，不要把安装成功当成开通成功。

3. 如果它找不到技能，把安装末尾显示的完整路径发给它，让它读取该目录的 `SKILL.md`。不要只说“刚才那个文件夹”。
4. Agent 应先检查能力、机型、系统和现有开关。已开启就不应重复发送定位；不满足硬件/资格要求就不能保证开通。
5. 你的 Agent 必须能读写本机文件、运行命令和跟踪进程。执行在云端容器里时，即使界面在 Mac 上也不算有本机 USB。

## 5. WorkBuddy 怎么装

1. 在发布页另下载 **apple-watch-hypertension-workbuddy.zip**，保留 ZIP，不解压用于导入。
2. 打开 WorkBuddy 的技能管理，选择“添加技能/导入 ZIP”（名称可能随版本变化），选择这个文件。
3. 等待导入完成，确认技能出现在列表中，重新开启对话。
4. 让它先读取 Skill，判断是否能在 **Mac 本机** 执行命令。ZIP 导入成功只说明技能被加载。
5. 本地依赖仍需准备：若它可以访问导入目录，让它在该目录运行 `bash install.command --prepare`。
6. 若导入目录不可见，使用第 2 节下载的普通 ZIP，在其中按第 3 节选 **3**。保留目录，将其完整路径告诉 WorkBuddy，让它读取这里的 SKILL.md 并使用这里的脚本。
7. 如果 WorkBuddy 只允许云端执行或无法运行本机脚本，这个版本就不能直接自动开通；按人工协作模式或换本地执行宿主。

已适配官方 ZIP 字段，但未逐版本实际导入/实机验证，不能把导入格式兼容说成全流程验证。不要把 WorkBuddy ZIP 导入豆包或 DeepSeek 聊天界面，假设同样有效。

## 6. 操作过程中，你需要配合哪些事

Agent 会在需要时提出具体操作。不要提前随意修改健康资料或定位设置。

1. **连接手机**：把与手表配对的 iPhone 用数据线接到 Mac。解锁 iPhone；若手机提示“信任此电脑”，自己点信任并输入手机密码。充电线不一定支持数据；连接失败时换数据线/接口。
2. **操作手机界面**：Mac 能用“iPhone 镜像”时由 Agent 检查可用工具；密码由你自己输入。如果没有镜像或控制工具，你直接在手机操作，告诉 Agent 实际结果。无需为了流程向聊天发送密码。
3. **记录真实位置**：临时定位之前，在“地图”点当前定位，查看新的当前位置地址。自己或 Agent 私下记下用于恢复比较；无需公开住宅地址、截图、设备序列号。
4. **身份来源**：Agent 会检查本地身份；缺少时说明自有身份或指定 DiPlay 实验身份的选择。证书和私钥不在发布包里。实验身份可能失效，不能反复重试承诺必成。
5. **验证香港定位**：临时发送开始后打开地图，点当前定位。必要时按 Agent 指示进入“设置 → 隐私与安全性 → 定位服务”，关闭，确认关闭后等至少 10 秒，再打开，返回地图刷新当前位置。菜单以你的 iOS 实际界面为准。只有新当前位置确实在香港才算成功，发送日志的 ACK 不算。
6. **回答健康问题**：到“健康 → 头像 → 健康检查清单 → 高血压通知”，按当前界面继续。年龄、是否曾被确诊等必须按事实填写。“血压偏高/临界”不能让 Agent 自行推断曾否确诊；不确定时先问清楚，不要为开通改生日或病史。
7. **结束和恢复**：Agent 停止发送后，你按提示拔掉 USB。刷新地图当前定位，必要时恢复定位服务原始状态；等新地址回到实际位置。然后再次打开健康，确认高血压通知仍显示开启。

发送单次最多十分钟。等你回答时计时不会暂停；时间不够就先停下并恢复，再说明下一步，不应偷偷续时。发送前让 Agent 把本地工具的完整路径和停止方法写给你，特别是 WorkBuddy 的本地目录。你可以随时说“停止并恢复真实位置”。

## 7. 怎样才算完成

请让 Agent 明确给出这五项结果，并说明是它看到的还是你确认的：

- 香港当前位置确实生效（若走了临时定位路径）。
- 健康中高血压通知已开启。
- 发送进程已经停止。
- 拔线后，新地图定位回到真实位置。
- 恢复后重新打开健康，通知仍开启。

安装完成、协议认证成功、地图旧卡片、天气变化都不能替代这些检查。没有出现通知也不能凭开关判断疾病情况；本流程没有验证未来永久保留或实际告警送达。

## 8. 常见问题

| 看到的情况 | 怎么做 |
| --- | --- |
| 安装时提示 `command not found: python3` | 你用了旧教程的 Python 命令。用第 3 节的 `bash` 和拖文件方式。 |
| 系统提示安装开发者工具 | 取消后按第 3 节重试；本安装入口不需要 Xcode。 |
| 下载超时、连接失败、校验失败 | 停止，不继续执行未知文件。保留最后几行错误让 Agent 分析；不要关闭证书验证或换不明镜像。 |
| 提示已有安装 | 安装程序不会覆盖旧版。按第 9 节更新；不要反复重试。 |
| 下载完成但依赖安装失败 | Skill 可能已复制但环境未就绪。终端会先打印“环境准备目录”。在访达按 ⌘ + Shift + G，粘贴该路径回车，找到 install.command，按第 3 节运行并选 **3**。若终端已关闭，Codex 打开 `~/.agents/skills/apple-watch-hypertension`，Claude Code 打开 `~/.claude/skills/apple-watch-hypertension`；WorkBuddy/选 3 模式打开你保留的工具文件夹。若目录不存在，重新运行原始安装即可。 |
| Agent 说找不到技能 | 新开对话/重启宿主；把完整安装路径给它，让它读取 SKILL.md。 |
| 没有控制手机的工具 | 由你在 iPhone 上操作并反馈。无需替 Agent 安装未知远程控制软件。 |
| 无法检测到 USB iPhone | 检查解锁、信任、线缆和接口；尽量只连接一部 iPhone，再让 Agent 检查。 |
| 功能仍然显示不可用 | 记录当前页面和错误，停止发送、恢复真实位置。不能据此伪造健康信息或无限重试。 |
| `uv version mismatch` | 先停止发送并完成恢复。访达按 ⌘ + Shift + G，打开 `~/Library/Application Support/apple-watch-hypertension/tools`，仅将里面的 `uv` 文件移到废纸篓，再运行安装入口（已有技能选 3）。不要删除身份或会话目录。 |
| 想中途退出 | 对 Agent 说“停止发送并恢复真实位置”；关闭聊天或终端窗口不等于停止后台发送。 |

**Agent 没反应时的停止办法：**

先在访达按 **⌘ + Shift + G**，Codex 输入 `~/.agents/skills/apple-watch-hypertension`，Claude Code 输入 `~/.claude/skills/apple-watch-hypertension`，回车打开；WorkBuddy/人工协作打开你保留的本地工具目录。进入 scripts 文件夹。

打开终端，输入 `bash `，把安装目录中的 `scripts/run.command` 拖进去，接着输入空格和 `sessions`，回车。它只列出本地会话，不连接手机。在 JSON 输出中找 **`"process_alive": true`** 的那一项，复制同一项的 **`"session"`** 后面引号中的实际值，不包含引号。例如 `"session": "abc123…", "process_alive": true`（示意，不能照抄）。probe 与正式发送是不同 ID，不能随便选最后一条。若所有项都是 false，当前列出的进程均已停止。

再用同样方式拖入 `run.command`，在后面输入 ` stop --session `，粘贴刚才的实际 ID，回车。随后用 ` status --session ` 和同一 ID 检查，看到 `process_alive: false` 才是进程已停。不要照抄“SESSION”占位符。实在不理解，先拔 USB、确认手机定位服务恢复原状，并找 Agent 协助检查；后台还有独立的十分钟上限。

终端中 **Control + C** 可以中断正在前台运行的下载/命令，但不会保证已独立启动的发送进程停止。不要把 Command + C（复制）当作中断。

## 9. 更新和卸载

**更新：**先停止所有发送，完成真实定位恢复，退出 Agent。找到旧技能目录，将整个 `apple-watch-hypertension` 文件夹移到技能父目录以外作为备份（仅改名留在技能目录下可能重复加载）。然后下载新发布包，重新安装。新版本成功检查后再删除备份。不要覆盖正在运行的目录。

Codex 默认技能目录为 `~/.agents/skills`，Claude Code 为 `~/.claude/skills`。`~` 表示你的个人文件夹。在访达按 **⌘ Command + Shift + G**，粘贴路径并回车即可打开隐藏目录。WorkBuddy 用其技能管理界面更新/移除；同时处理你保留的本地工具文件夹。

**卸载：**先停止发送并恢复手机，再从宿主移除技能或将对应技能文件夹移到废纸篓，重新打开宿主。卸载技能不会自动关闭健康中的通知。

本地凭据、会话和工具独立存放于：

`~/Library/Application Support/apple-watch-hypertension/`

这包含私密数据，不要上传到 GitHub。确认不再需要后，可用上述访达“前往文件夹”方式打开并移到废纸篓。不要在发送中删除它。如果删除了共享工具目录，其他安装副本需要重新准备环境。

## 10. 向别人求助时发什么

提供 Mac/系统版本、Agent 的产品名称和运行模式、出错步骤、最后几行错误即可。隐藏用户名、真实地址、API Key、证书、私钥和设备标识。不要上传整个会话目录或手机健康截图。

本项目实机经历和适配状态见[复盘](retrospective.md)与[适配表](agents.md)。普通用户按本指南操作，开发者测试命令不属于安装步骤。
